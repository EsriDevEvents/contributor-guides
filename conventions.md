# Conventions for repositories

We have created a [repository template](https://github.com/EsriDevEvents?q=repo-template&type=all&language=&sort=#org-profile-repositories) that can be used to create your own:

![repository-template](https://github.com/user-attachments/assets/fb0f9301-1c16-495c-8303-51aa53e08c08)


## General rules


| Session type        | Repo title                  | Topics                                              | E.g.                                                                           |
| ------------------- | --------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------ |
| Technical sessions  | Session to name<sup>1</sup> | `technical-session`, `talk`                         | `arcgis-online-imagery-analysis-using-python-YYYY`                                  |
| Presummit workshops | Session to name<sup>1</sup> | `presummit-workshops`, `workshop-materials`         | `deep-dive-into-arcgis-arcade-and-automation-with-arcgis-field-maps-YYYY`           |
| Plenary demos       | Section name<sup>1</sup>    | \[conference\]-\[continent\]\-plenary-\[topic\]-\[year\] | `ds-europe-plenary-web-YYYY`, `fed-plenary-web-YYYY`, `uc-usa-plenary-native-YYYY` |
| User presentations  | Session to name<sup>1</sup> | `presummit-workshops`, `workshop-materials`         | `python-toolboxes-for-developers-and-novice-users`                             |
| Demo theater        | Session to name<sup>1</sup> | `demo-theater`                                      | `an-introduction-to-javascript-for-future-web-developers-YYYY`                      |
| Speedgeeking        | Edition name                | speedgeeking-\[conference\]-\[continent\]-\[year\]  | `speedgeeking-ds-usa-YYYY`                                                                             |

> (1)  [Slugify the title of the sessions](https://slugify.online/) using lowercase and separate with dashes 

In addition to the previous topics, add also the followings:

   * `esri` and `arcgis`
   * As many technologies as covered (full list below in the instructions)
   * Developer summits: 
	   * `esri-devsummit`
	   * `ds-` followed by the full year (e.g. `ds-YYYY`) .
	   * `ds-` followed by the continent (e.g. `ds-usa` or `ds-europe`).
   * User conferences:
	   * `esri-user-conference`
	   *  `uc-`followed by the full year (e.g. `uc-YYYY`)
   * Federal GIS Conference
	   * `esri-federal-gis-conference`
	   * `fed-` followed by the full year (e.g. `fed-YYYY`)
